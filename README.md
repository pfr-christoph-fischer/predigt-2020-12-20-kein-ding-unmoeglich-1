# Kein Ding unmöglich

Enttäuschte Hoffnungen. Abgesagte Pläne. Bittere Traurigkeit. Jedes Wort der Hoffnung entlockt nur noch ein bitteres Lächeln. Aber bei Gott ist kein Ding unmöglich. Seine Antwort auf all das: Ein Kind. Und große Freude. <em> Kurzfassung für den Telefongottesdienst am 20.12.2020</em>
